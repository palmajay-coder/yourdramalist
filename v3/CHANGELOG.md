# Changelog

## 3.0.0 public beta — 2026-11-06

Initial open-source V3 snapshot. The running app identifies itself as `3.0.0-dev`; the manifest uses `3.0.0` for compatibility. This beta label does not claim stable installation/playback support on every Nuvio device.

- Connect, Community/Discover list selection, drama details, actor/director filmographies and country catalogs.
- Featured-list heading banner, light/dark themes, moving TMDB poster background and owner wallpaper administration.
- Preferences with optional poster-rating keys, independent badge choices, illustrative review/poster previews and title-filter settings.
- Confirm summary, automatically generated encrypted manifest URLs, Copy and full-width Install in Nuvio action.
- Ported original rating/verdict/helpful-review output and V3-specific filmography extraction.
- Classic Blue 256×256 YDL manifest icon.
- Tests and public-release documentation. Saved browser-page test captures replaced by synthetic fixtures in the public suite.

See README for inherited data-matching and live-validation limits. Recommendations and video backgrounds remain deferred.
