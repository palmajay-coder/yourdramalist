# Changelog

## 1.0.3

- Show individual public watchlist categories before custom lists in Community. Connect accepts usernames, profile URLs, and drama-list URLs.
- Restore the poster ratings toggle and preview in a dedicated tab alongside BetterPosters.
- Prefer TMDB artwork for standard catalog posters when an IMDb match provides it.
- Keep watchlist cards aligned with a thumbnail placeholder and remove their generated descriptions.
- Separate Community profile results into Watchlists and Custom lists tabs with shared selections. The optional All Dramas & Films catalog appears below the individual watchlists.

- Distinguish empty watchlists from missing poster artwork.

- Fill missing Community watchlist thumbnails with matched artwork from titles in the list.

- Recover missing catalog release years from matched metadata or the exact MyDramaList title page.

## 1.0.2

- Fix manifest issue for built-in user watchlists. 
- Add BetterPosters as an optional artwork provider for YDL catalogs. Paste a BetterPosters poster URL pattern in Preferences and generate a new install link.

## 1.0.1

- Show a diagnostic code when the server rejects a manifest request. The matching server log records only the code, time, and failure category.
- Show a separate connection message when the browser cannot reach the server.

## 1.0.0

First stable release of YourDramaList.

- Browse country catalogs and weekly collections, and add actor and director filmographies.
- Cycle through Featured, Recent Activity and Trending lists in the setup banner. The banner refreshes at midnight Pacific, and weekly collections refresh on Mondays at midnight Pacific.

See [beta notes](BETA_NOTES.md) for verification and data limitations. Recommendations and video backgrounds remain deferred.
